# Manual check — 눈으로 확인할 것들

빌드/테스트가 못 닫는 시각·몰입 영역. 실행: 터미널 1 `.venv/bin/uvicorn
app.api.main:app --port 8765`, 터미널 2 `cd frontend && bun run build`
후 브라우저에서 `http://127.0.0.1:8765/` (또는 dev 모드: `bun run dev` →
`http://localhost:5173/`). llama-server(8080)가 켜져 있어야 대화가 됨.

## Phase 1 — 첫 플레이 화면

- [ ] 타이틀: 어둑한 심연 그라디언트 무드가 "난파섬"답게 느껴지는가.
      "Still Here" 타이포/[시작하기] 버튼 배치가 어색하지 않은가.
      세이브 코드 자리(비활성)가 거슬리지 않는가.
- [ ] 시작 → 수리공 오프닝: 첫 대사가 자연스럽게 페이드인되고, 선택지
      3개(공감/도발/회피 톤)가 보이는가. 오프닝 톤이 수리공답게 느껴지는가.
- [ ] 선택지 클릭 → 내 말풍선(오른쪽)/수리공 말풍선(왼쪽) 구분, 대기 중
      typing 표시와 버튼 비활성이 자연스러운가.
- [ ] 여러 턴 진행하며 선택지 개수가 3→2로 줄어드는 순간을 체감할 수
      있는가 (몰입의 심장 — awareness 진행감).
- [ ] 캐릭터/배경 이미지 없는 상태의 그라디언트 플레이스홀더가 견딜 만한가
      (이미지 드롭인 전까지의 상태 평가).
- [ ] 욕설 등 디니리스트 단어 입력 시(자유 입력 열리면) warning 블록이
      수리공 말풍선과 확실히 다른 시스템 톤으로 보이는가. 이전 선택지가
      그대로 살아 있는가.

## Phase 2 — 재방문

- [ ] 몇 턴 플레이 → 브라우저 완전히 닫기 → 다시 열기: 타이틀 버튼이
      [이어하기]로 바뀌고 안내 캡션이 떠 있는가. 문구가 과하지 않은가.
- [ ] [이어하기] → 지난 대화가 dim 처리 + "여기까지 지난 대화" 구분선
      아래로 이어지는가. 지난 말풍선이 다시 애니메이션되지 않고 "가라앉은"
      느낌인가. 최신 메시지로 스크롤돼 있는가.
- [ ] 복원된 선택지로 바로 이어서 플레이가 되는가 (끊긴 느낌 없이).
- [ ] (선택) 시크릿 창에서 열면 [시작하기]로 새 세션이 시작되는가.
