# ADR 0036: 세이브 코드 형식 — 가독 단어 프리픽스 + 랜덤 4자 (백필)

- Status: Accepted
- Date: 2026-08-19 (결정 시점 — 기록은 2026-08-20 백필)
- Deciders: Arden (인간 재판정 b), Claude (직전 talpi 런)

## Context

세이브 코드는 계정 없는 이 게임의 유일한 기기 이동 다리다 — 사람이
읽고, 옮겨 적고, 입으로 불러줄 수 있어야 한다. 직전 런에서 완전 랜덤
8자 구현이 나왔다가 인간 리뷰에서 reject — "MAST-7X2K 류"라는
mechanic-spec 의 원래 그림(짧은 프리픽스 + 랜덤)이 가독성 의도였음을
재판정(선택지 b)으로 확정하고 재구현했다. 락인됐으나 ADR 미기록이어서
백필한다.

## Decision

1. **형식**: `단어4자-랜덤4자` (VARCHAR(9) 유지, 예: `MAST-7X2K`).
   프리픽스는 허용 알파벳 내 4자 영단어 **15개 목록**
   (`app/save_code.py` 의 `SAVE_CODE_PREFIX_WORDS` — 섬/바다 테마)
   중 랜덤, 서픽스는 허용 알파벳 랜덤 4자.
2. **허용 알파벳**: `ABCDEFGHJKMNPQRSTUVWXYZ23456789` (31자) — 시각
   혼동 문자 0/O, 1/I/L 제외. 프리픽스 단어도 전 글자가 이 알파벳
   안이어야 함 (모듈 assert로 강제 — MOON/SAIL/ISLE 류는 O/I/L 때문에
   불가). 단어 목록 내용 자체는 구현 재량.
3. **엔트로피 트레이드오프 수용**: 완전 랜덤 8자(31^8 ≈ 2^39.6) 대비
   단어 프리픽스는 15 × 31^4 ≈ 2^23.8 로 줄어든다. 지인 배포 규모에서
   충분하고, 무차별 대입은 이미 의식적 수용 항목 (ADR 0034 재검토
   목록) — 가독성/구술 전달성이 익명 캐주얼 게임의 세이브 코드에선 더
   큰 가치라는 판단.

## Alternatives Considered

- A. ★ chosen — 단어 프리픽스 + 랜덤 4자.
- B. 완전 랜덤 8자 — 기각 (인간 재판정). 엔트로피는 크지만 읽기/옮겨
  적기/불러주기가 나쁘다. 이 코드의 존재 이유가 사람 손을 타는
  브리지라는 점과 상충.
- C. 긴 단어 조합 (diceware 류, `CORAL-STORM-7X` 등) — 기각. VARCHAR(9)
  파괴적 변경 + 타이틀 화면 입력 UI가 무거워짐. 규모 대비 과잉.

## Consequences

- 형식 정의와 단어 목록이 같은 파일(`app/save_code.py`)에 단일 정의 —
  목록 변경은 코드 한 곳.
- 기존 발급 코드와의 하위 호환: 형식 정규식이 프리픽스를 "목록 내
  단어"로 강제하지 않고 알파벳 4자로만 검증 — redeem 은 목록 개정과
  무관하게 동작.
